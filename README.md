# Chinook Music Store - SQL Data Analysis Project

## 📌 Project Overview
This project presents an end-to-end database analysis of the **Chinook Digital Media Store** using **MySQL**. The analysis focuses on auditing global sales performance, mapping customer behavior, and providing data-driven strategic recommendations to optimize revenue.

This project was co-developed as part of the **NTI Data Analysis Program** under the mentorship of **Mennatullah Tarek**.

* **Aya El-Mowafy:** Focused on **Sales Performance Analysis**, tracking annual/quarterly trends, geographic sales distribution, and identifying underperforming/dead-stock assets.

---

## 📊 Key Insights & Results

### 1. Sales Performance (Global Trends)
* **Geographic Dominance:** North America (USA & Canada) serves as the primary revenue engine, contributing over **60% of total global sales**.
* **Low Baseline AOV:** The store's Average Order Value (AOV) stands at **$5.65**, driven heavily by single-track purchases ($0.99), uncovering a massive opportunity for product bundling.

### 2. Customer Behavior & Segmentation
* **High-Value Profiles:** The Top 10 Spenders generate an AOV of **$7.44**, which is **31% higher** than the store average.
* **Cross-Genre Potential:** High-value customers show strong engagement with diverse categories, including non-music content like "TV Shows," which can be leveraged to maximize cart value.

---

## 🚀 Strategic Recommendation: The VIP-Referral Engine
To scale revenue, we designed a data-driven **Tiered Referral Program** targeting look-alike audiences in top markets (USA, Czech Republic, Canada):
* **The Incentive:** A **30% Loyalty Discount** on genre-specific packages for our Top 10 customers.
* **The Financial Impact:** Financial modeling projects an immediate **153% ROI** per referral transaction and an expansion of Customer Lifetime Value (LTV) to **$39.55**.
